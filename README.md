# 🎵 Sistema Musical — Front-end (HTML5 & CSS3)

Este repositório contém a interface front-end do **Sistema Musical**, uma aplicação web desenvolvida de forma modular para a gestão de artistas, músicas e álbuns. O projeto inclui as páginas de autenticação, menu de navegação, consulta e formulários de cadastro com componentes responsivos.

---

## 📁 Estrutura do Projeto

O projeto é composto pelos seguintes ficheiros principais:

```text
.
├── index.html              # Menu principal do sistema
├── login.html              # Tela de autenticação/login
├── cadastro_artista.html   # Formulário e listagem de artistas
├── cadastro_musica.html    # Formulário e listagem de músicas
├── listagem_musicas.html   # Biblioteca musical com filtros de pesquisa
└── styles.css              # Folha de estilos centralizada (Aulas 1 a 4)
